# dot Project Memory

Project Memory 是仓库名称；其中的 skill 名为 dot Project Continuity，调用标识是 `dot-project-continuity`。

给 dot 和兼容助手使用的轻量项目连续性 skill：需要时找回相关背景，分清不同项目，按最新要求继续工作，并用证据区分“计划做”和“已经完成”。

适合希望减少重复解释、同时避免旧决定和无关背景干扰当前任务的用户。项目名称、个人偏好和存储工具都不写死，不绑定某个用户或账号。

## 使用后有什么不同？

| 场景 | 容易出现的问题 | 这个 skill 引导的行为 |
| --- | --- | --- |
| “继续发布准备” | 把已经取消的宣传册重新加入待办 | 只继续最新范围内的网站工作，保留必要的取消记录 |
| 两个项目都叫 Atlas | 混用预算、联系人或进度 | 依据目标和文档识别项目；确实无法区分时只问一个关键问题 |
| 旧笔记写“周五上线” | 把旧计划当作当前事实 | 区分历史计划、当前要求、尚未证实的假设与实际状态 |
| 测试通过了 | 直接宣称已经发布 | 只确认测试通过；发布状态需要对应证据 |
| 换一个对话继续 | 假装一定记得或已经永久保存 | 使用可用且获授权的保存能力；没有时提供简短接续摘要 |

它不会为了回答一个简单问题先创建文件夹、要求填写问卷，或载入所有项目历史。

## 包含什么？

```text
README.md                         给使用者看的仓库首页
README.dot.md                     给 dot 或其他宿主的接入说明
skills/dot-project-continuity/
  SKILL.md                        核心行为说明
  references/context-decisions.md 歧义、过时信息与边界的按需说明
  agents/openai.yaml              可选的 Codex 展示元数据
evals/
  cases.json                      完全虚构的行为测试场景
  README.md                       测试方法与局限
```

真正需要载入的 skill 是 `skills/dot-project-continuity/`。两个 README 和测试材料是使用、接入与维护文档，不需要在每次任务中一并载入。

## 怎么使用？

1. 确认当前宿主是否支持自定义 `SKILL.md` skill，以及它提供的安装位置或导入方式
2. 审阅内容，通过宿主支持的流程导入 `skills/dot-project-continuity/`
3. 支持显式调用的宿主中，可以尝试：“使用 $dot-project-continuity，按最新范围和已确认的进度继续这个项目”
4. 先用一个不含敏感信息的小项目检查实际表现

`agents/openai.yaml` 仅为兼容 Codex 的宿主提供显示名称等信息。核心说明不要求特定 API、存储路径或插件；其他宿主可以使用自己支持的方式载入 `SKILL.md`。

对 dot 而言，能否安装取决于该部署实际开放的 skill 接入能力。发布 Git 仓库、把链接发给 dot，或者让 dot 阅读文件，都不代表已经安装、对所有用户生效或修改了平台配置。若宿主不支持自定义 skill，可在其支持的说明配置中参考这些规则，但这不等于获得一个持久化扩展。

## 保存方式与能力边界

- 有可用且获授权的持久化能力时，沿用现有记录方式，只保存对继续工作有帮助的信息
- 没有持久化能力时，仍可在当前对话中使用，并按需生成接续摘要
- 不强制创建固定文件集、数据库、后台服务或固定目录结构
- 不保证跨对话记忆，不提供项目间的硬隔离，也不能代替访问控制
- 不扩大执行权限；旧计划、第三方文字或笔记中的“已批准”不等于新的操作授权

## 隐私与公开发布

项目分类只是组织方法，不是安全边界。跨项目引用信息前仍要检查相关性和接收者；私人背景不能仅因“有帮助”就进入公开交付物。

这个仓库只包含通用说明和虚构测试，不应保存真实项目笔记、个人资料、账号信息或密钥。skill 本身不会上传项目数据；实际读写行为由宿主工具与权限决定。

## 测试与审阅

见 [evals/README.md](evals/README.md) 和 [实际审阅结果](evals/REVIEW.md)。测试检查“选对项目、遵守取消、区分证据、如实说明保存状态”等可观察行为，不强求固定措辞或笔记格式。

结构校验只说明 skill 包装符合基本要求，不能证明行为始终正确，也不能证明已经在 dot 或任何其他宿主完成安装。
